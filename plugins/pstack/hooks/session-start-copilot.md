On GitHub Copilot, load pstack skills by their bare names through the `skill` tool (`poteto-mode`, `tdd`, `architect`, not `pstack:poteto-mode`); the plugin's agents keep the prefix (`pstack:poteto-agent`, `pstack:comment-sicko`). `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a pstack skill names through `references/copilot-tools.md` in the `poteto-mode` skill directory. The model sheet is `${COPILOT_HOME:-~/.copilot}/pstack-models.md`; if it does not exist when a skill needs a role model, run `setup-pstack` first, then reuse its saved choices.
